# Доступ из интернета

Подготовлен HTTPS-вход через Cloudflare Quick Tunnel. Публикация пока не выполнена: подключение туннеля остановлено после ошибки системного DNS. LaunchAgent-конфигурации сохранены в `.local/*.plist.disabled`, автозапуск отключён. Это временный адрес: приложение по-прежнему обслуживает этот Mac. При выключении, сне или потере сети сайт недоступен; перезапуск туннеля выдаёт другой адрес. Для постоянного хостинга нужен отдельный сервер либо именованный туннель с доменом.

## Службы

- `local.erut.public`: отдельный сервер `server/public.ts` на `127.0.0.1:4174`. Доступен только локально для туннеля. Авторизация по тем же серверным учётным данным, что и в офисной сети.
- `local.erut.tunnel`: Cloudflare Tunnel, внешний TLS, соединение с указанным сервером.
- `local.erut.server`: прежний офисный сервер на `0.0.0.0:4173`.

LaunchAgent-файлы находятся в `~/Library/LaunchAgents`. Журналы и учётные данные — в исключённой из Git директории `.local`. Публичный сервер выдаёт Secure / HttpOnly / SameSite=Strict cookie, проверяет HTTPS Origin и закрывает данные и приложение до входа. Серверные тесты проверяют обе схемы доступа. Ограничение попыток входа публичного сервера общее для туннеля (10 ошибок за 15 минут).

Адрес туннеля печатается в `.local/local.erut.tunnel-error.log`. После обновления сборки следует перезапустить `local.erut.public`, чтобы обновить список разрешённых ресурсов страницы входа.

Остановить публичный доступ:

```sh
launchctl bootout gui/$(id -u)/local.erut.tunnel
launchctl bootout gui/$(id -u)/local.erut.public
```

Это не останавливает офисный сервер. LaunchAgent снова запускается при следующем входе владельца в macOS.
