# Локальный сервер eRut

Адрес: http://10.242.184.80:4173/. Сервер слушает 0.0.0.0:4173.

Служба macOS `local.erut.server` запускает `server/start.ts` через Node.js. LaunchAgent: `~/Library/LaunchAgents/local.erut.server.plist`. Служба перезапускается после сбоя и запускается при входе владельца Mac в систему. Для доступа коллег компьютер должен быть включён и подключён к офисной сети.

## Доступ

Отдельная страница входа не содержит отчётных данных. Сервер проверяет пароль по scrypt-хешу из `.local/credentials.json`; этот файл исключён из Git и имеет права 0600. Пароль отсутствует в клиентской сборке. Сервер выдаёт случайную HttpOnly / SameSite=Strict cookie на 8 часов; выход отзывает сессию. После перезапуска сервера потребуется повторный вход. Старый sessionStorage-доступ и вход без пароля удалены.

Без сессии закрыты приложение, документы, изображения и остальные файлы, кроме ресурсов страницы входа. Защищённые ответы не кэшируются. Попытки входа ограничены; POST-запросы проверяются по Origin. Офисный адрес использует HTTP, поэтому шифрования транспорта нет. Это не настройка для публичного интернета.

## Обновление

1. `npm run build`
2. `npm test && npm run test:server && npm run check:server`
3. `launchctl kickstart -k gui/$(id -u)/local.erut.server`

Перезапуск после сборки нужен для обновления списка разрешённых ресурсов страницы входа. Ручной запуск при остановленной службе: `npm start`. Журналы: `.local/server.log`, `.local/server-error.log`.

## Карта

MapLibre GL JS и worker загружаются с того же локального сервера. Подложка и шрифты карты используют HTTPS-ресурсы CARTO; устройству нужен доступ к этому сервису. Объекты добавляются при готовности стиля, независимо от полной загрузки сетевых тайлов.

23 сентября проверены вход, подложка, кластеры, открытие объекта и выход через офисный IP в браузере этого Mac. Другие устройства и их сетевые ограничения не проверялись.
