# Локальная статическая версия RUT.digital

С 23 сентября приложение работает без серверной авторизации. `npm run build` создаёт `dist`, `npm start` раздаёт его на `0.0.0.0:4173`. Служба macOS `local.erut.server` использует Vite preview.

Вход проверяется во frontend по `data/access.json`, сессия хранится в sessionStorage 8 часов. Пароль и данные доступны в клиентской сборке. `server/app.ts`, `server/start.ts` и `server/public.ts` оставлены как архив серверной реализации и сейчас не запускаются.

После изменения исходников выполните `npm test && npm run build`. Перезапуск статического сервера не требуется. Публичная публикация настроена через `.github/workflows/pages.yml`.

Подложка MapLibre использует HTTPS-ресурсы CARTO; для неё нужен интернет. Worker, шрифты интерфейса, изображения и слайды находятся в сборке.
