# eRut — мониторинг университета

SPA на Vue 3 + TypeScript, Vite, MapLibre GL JS. Работает на статическом хостинге без серверного API.

## Запуск и сборка

```sh
npm ci
npm run dev
npm test
npm run build
npm start
```

`npm start` раздаёт сборку в офисной сети на порту 4173. `npm run preview` — только на localhost.

## Вход

Учётная запись задаётся в `data/access.json`. Проверка выполняется во frontend, сессия хранится в sessionStorage вкладки 8 часов. Это условный вход для демонстрации интерфейса, а не защита: учётные данные, JSON и документы доступны в публичной сборке. Серверный код в `server/` сохранён для будущего восстановления серверной авторизации, в статической версии не используется.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет, собирает и публикует `dist` при изменении `main`. В настройках репозитория Pages нужно выбрать Source: GitHub Actions. Относительные пути поддерживают размещение в `/erut-prototype/`, маршруты используют hash.

## Возможности

- Главная: четыре основных виджета по умолчанию, ещё два добавляются через настройки. Все шесть виджетов перемещаемые, изменение ширины, скрытие, сброс; сохранение раскладки в localStorage. Для сенсорных устройств доступны кнопки перемещения.
- Карта: MapLibre GL JS, восемь кампусов Москвы и Сочинский филиал. Круги по виду образования, численности и площади; отдельный слой четырёх строек. Выбор кампуса раскрывает корпуса и диаграмму контингента. Свободный зум и перемещение отключены. Подробные слои и готовность строек помечены «мок». См. docs/map.md.
- Приём: ВО / СПО, показатели, фильтрация и сортировка подразделений, рейтинги программ, квоты, география, экспорт текущей таблицы в CSV.
- Календарь: месяцы, список всех событий, категории, многодневные события, карточки. События без точного дня вынесены в список.
- 10 карточек институтов/академий связаны с инфраструктурой и данными приёма.
- Наука, финансы, государственное финансирование, девять стратегических инициатив.
- Сводка вопросов, требующих внимания; отдельный просмотр 21 страницы документа с вписыванием целиком.
- 45 подробных обзоров: университет, полный контингент, гимназия, колледжи, программы, исследования, финансы и проекты. Карточки связаны между собой; возврат сохраняет вкладку.
- Боковая панель автоматически сворачивается до логотипа и значков. Глобального поиска нет; каталоги имеют локальные фильтры.
- Адаптивная вёрстка, локальный шрифт Golos Text, анимации с поддержкой prefers-reduced-motion.

## Данные и ограничения

Все сведения об университете — только из предоставленного PDF «Текущий статус деятельности РУТ (МИИТ)_v12», сентябрь 2026. Данные хранятся в `data/*.json`, фотографии извлечены из PDF без генерации. Полный PDF находится в `public/source.pdf`, изображения страниц — в `public/slides/`. `source` означает номер страницы PDF (начиная с 1), а не внутренний номер слайда, который на 1 меньше.

- `institutes.json`: очная форма, страница 5. `objects.json`: характеристики инфраструктуры, страница 3. Контингент здания и контингент института могут различаться; численность на карточках объектов местами округлена в источнике.
- В слайде по СПО сумма зачисленных по пяти подразделениям — 1 386; итог — округлённые 1,39 тыс. Оба представления сохранены.
- На странице 11 суммы статей доходов (23 039 млн ₽) и расходов (22 619 млн ₽) отличаются от авторских итогов (22 919 и 22 620 млн ₽). Прибыль на графике — 300 млн ₽. Расхождения сохранены и обозначены в интерфейсе.
- На страницах 11 и 12 отдельные показатели финансирования различаются; они относятся к разным таблицам и не объединены искусственно.
- Видеопотоки в PDF отсутствуют: вкладка явно показывает «Трансляция не подключена», без имитации живого видео.
- Координаты — приблизительное размещение объектов по улицам из презентации, не кадастровые или подтверждённые геоданные. Номера отдельных корпусов, не указанные в источнике, не добавлены.
- Карта использует внешние тайлы CARTO / OpenStreetMap и картографические подписи; это подложка, а не источник показателей университета. Для неё нужен интернет. При недоступности подложки список объектов остаётся доступным. Университетские JSON и PDF не отправляются внешним сервисам.
- Сводка «В фокусе» отражает отчёт, а не поток онлайн-уведомлений. Статусы не обновляются автоматически. Данные и даты сохранены в контексте сентября 2026 года.

## Структура

- `src/App.vue` — оболочка, обзор, навигация и связанные карточки.
- `src/components/Admissions.vue`, `Calendar.vue`, `Analytics.vue` — разделы платформы.
- `src/components/CampusMap.vue` — MapLibre, полигоны и маркеры; worker собирается отдельно Vite.
- `src/components/LineChart.vue` — SVG-график.
- `src/style.css` — адаптивная тема и анимации.
- `data/` — JSON с показателями, сущностями, событиями и стилем карты.

## Проверка

`npm run build` проверяет строгую типизацию и создаёт production-сборку. `npm run test:data` проверяет связи сущностей, доступность источников/изображений, хронологию событий и контрольные показатели. В браузере вручную проверены демовход, карта и карточки, фильтры ВО/СПО, календарь на границе месяцев, сохранение раскладки после перезагрузки, просмотр источника и мобильная компоновка.

## Обновление интерфейса

Карточки раскрываются в рабочие окна 96% ширины и 94% высоты экрана (на мобильных — 97% высоты). Основной текст — 14–17 px, вспомогательные подписи — 13 px. Дашборды используют интерактивные графики, переключение рядов, кольцевые диаграммы с выделением категорий и цветовые акценты. Подробные рейтинги приёма и примечания доступны по раскрытию. Карта использует `data/map-config.json` с границами Москвы; запись Сочи сохранена в исходных данных, но исключена из карты, её списка и глобального поиска.

### Визуальная идентичность институтов

`data/institute-identities.json` закрепляет за каждым из 10 институтов собственный цвет, светлый фон и тематический символ. Это оформление прототипа, а не официальная символика подразделений. `src/identity.ts` и `InstituteBadge.vue` применяют справочник к каталогу, карточкам, главному обзору, поиску, аналитике приёма, рейтингам и карте. Цвета не зависят от сортировки и выбранного показателя. В общих корпусах отображаются значки всех связанных институтов; объекты без такой связи имеют нейтральный маркер. Учебные и финансовые данные не изменены. Проверка справочника контролирует полноту, уникальность цветов и символов и контраст текста не ниже 4,5:1.

### Рабочая область без длинной ленты

На экранах от 1000 × 620 основная область занимает доступную высоту окна: заголовок и навигация остаются на месте. Главная показывает пару выбранных виджетов; остальные доступны переключателями. Пользовательская настройка, порядок и ширина блоков сохранены. Аналитика разделена на обзор и подробные вкладки. Каталоги институтов, проектов и событий получили пагинацию с поиском и фильтрами. Календарь открывается событиями; месячный вид показывает выбранный день и его повестку рядом. Длинные таблицы и пояснения прокручиваются внутри своих панелей. На телефонах сохраняется естественная прокрутка и один активный виджет, без уменьшения всей страницы до нечитаемого масштаба.

### Дизайн-система «Траектория»

Раздел `#/design` открывается из нижней части бокового меню, рядом с «О презентации». Восемь разделов описывают характер интерфейса, визуальные основы, библиотеку компонентов, идентичности институтов, визуализацию данных, UX-сценарии, доступность и правила разработки. Живые примеры используют рабочие компоненты приложения: можно менять варианты и размеры кнопок, проверять ошибки формы, переключать вкладки, листать примеры и открывать большое окно.

- `src/components/ui/` — 10 базовых компонентов: `UiButton`, `UiInput`, `UiSelect`, `UiTabs`, `UiSwitch`, `UiBadge`, `UiPanel`, `UiMetric`, `UiDialog`, `UiEmptyState`. Единая точка импорта — `index.ts`.
- `InstituteBadge` и `PageControls` дополняют библиотеку идентичностью подразделений и пагинацией.
- `data/design-tokens.json` — цвета, размеры, отступы, радиусы, тени и длительности переходов; `src/design/tokens.ts` переводит их в CSS-переменные `--er-*`.
- `src/design/ui.css` — общие состояния компонентов; `src/design/system.css` — оформление живого руководства.
- `data/design-system.json` — тексты правил и контракты компонентов.
- `docs/design-system.md` — полное руководство. Копия `public/design-system.md` доступна для скачивания из приложения; при изменении руководства обновляются оба файла.
- `docs/qa-report.md` — область проверки и ограничения прототипа.

`UiDialog` управляет фокусом, Escape, блокировкой фонового интерфейса и возвратом к инициатору. `UiTabs` поддерживает стрелки, Home и End. `UiSelect` сохраняет тип значения модели, включая числовые номера страниц. `UiInput` связывает подпись, пояснение и ошибку с полем. Декоративные движения учитывают системное предпочтение reduced motion.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { UiButton, UiInput, UiPanel } from './components/ui';
const query = ref('');
</script>

<template>
  <UiPanel title="Поиск подразделения">
    <UiInput v-model="query" label="Название или сокращение" />
    <UiButton variant="secondary" @click="query = ''">Сбросить</UiButton>
  </UiPanel>
</template>
```

`npm test` запускает проверки данных и 16 тестов UI/сценариев. `npm run test:ui` — только компоненты и сценарии. Тесты охватывают доступные состояния, клавиатуру, управление фокусом диалога, числовой select, пустые графики, авторизацию, поиск института с переходом к источнику и обратно, периоды событий и содержимое CSV после фильтрации.

## Доступ для коллег по локальной сети

```sh
npm run build
npm run preview:lan
```

Сборка доступна на порту 4173 по LAN-адресу Mac. На момент настройки: **http://10.242.184.80:4173/** (активный Ethernet en7; Wi-Fi en0 не подключён). Коллегам в офисном Wi-Fi нужен маршрут к этой сети. Удалённый доступ с другого устройства не проверялся. Mac и процесс preview должны оставаться включёнными; адрес может измениться при смене сети. Публичный хостинг и туннели не использовались.

Связи между исходным отчётом и разделами описаны в `docs/content-coverage.md`. Проверки — в `docs/qa-report.md`.
